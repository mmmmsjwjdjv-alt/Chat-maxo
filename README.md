# MAXO CHAT — پیام‌رسان بومی اندروید (Native Android Java & XML)

پیام‌رسان حرفه‌ای، تماماً بومی (Native) اندروید توسعه داده شده با زبان **Java** و رابط کاربری مبتنی بر **Android XML Layouts**، طراحی مدرن مونوکروم (مشکی و سفید)، فونت زیبای فارسی **وزیرمتن (Vazirmatn)** و اتصال به منبع داده اصلی:

`https://tk-server.ir/json/CHAT-MAXO.json`

---

## 📱 راهنمای دانلود و نصب APK از طریق گوشی موبایل

این پروژه برای کاربرانی که کل کارهای خود را از طریق گوشی هوشمند انجام می‌دهند طراحی شده است:

### ۱. بارگذاری روی مخزن GitHub:
1. در مرورگر گوشی به سایت [github.com](https://github.com) رفته و وارد حساب خود شوید.
2. مخزن جدیدی به نام `MAXO-CHAT` ایجاد کنید.
3. پروژه را از منوی تنظیمات AI Studio به گیت‌هاب ارسال کنید (Push to GitHub) یا فایل ZIP را دانلود و آپلود نمایید.

### ۲. ساخت خودکار فایل نصبی APK:
1. در صفحه مخزن گیت‌هاب در گوشی، وارد تب **Actions** شوید.
2. گردش‌کار **Build & Release Native Android APK** به طور خودکار پروژه Java را کامپایل کرده و تست‌های واحد را اجرا می‌نماید.
3. پس از اتمام ساخت (تیک سبز)، بر روی بیلد ضربه زده و از بخش **Artifacts** فایل **MAXO_CHAT_APK** را دانلود و مستقیماً روی گوشی نصب کنید.
4. با ایجاد تگ نسخه (مثلاً `v1.0.0`)، فایل نصبی به صورت خودکار در بخش **Releases** گیت‌هاب نیز منتشر خواهد شد.

## 🌐 بررسی فنی منبع داده آنلاین (CHAT-MAXO.json)

منبع داده اصلی برنامه نشانی زیر است:
`https://tk-server.ir/json/CHAT-MAXO.json`

### نتایج استعلام زنده و تحلیل رفتار سرور:
1. **متد GET (دریافت داده‌ها):**
   - سرور LiteSpeed با کد HTTP 200 پاسخ داده و محتوای JSON را ارسال می‌کند (در حال حاضر آرایه خالی `[]`).
   - اپلیکیشن اندروید به صورت غیرهمگام (Background Thread) با زمان انتظار ۸ ثانیه و مکانیزم تلاش مجدد، داده‌ها را واکشی و در `RecyclerView` نمایش می‌دهد.
2. **متد PUT و POST (ارسال و ذخیره‌سازی داده‌ها):**
   - ارسال متد `PUT` به این آدرس با خطای **HTTP 501 (Not Implemented)** از طرف وب‌سرور LiteSpeed مسدود می‌شود.
   - ارسال متد `POST` مستقیماً فایل استاتیک را بازمی‌گرداند و تغییری در داده‌ها روی هاست ذخیره نمی‌کند.
3. **رمز ویرایش قدیمی (MAXO):**
   - طبق اصول امنیتی، رمز ویرایش در لاگ‌ها یا کدهای عمومی افشا نمی‌شود.
   - برنامه به صورت کاملاً شفاف این محدودیت فنی را در دیالوگ وضعیت سرور به کاربر نمایش می‌دهد و پیام‌های ارسالی کاربر را به صورت پیش‌نویس محلی ذخیره می‌کند تا هیچ ادعای کذبی مبنی بر ارسال سراسری به کاربران دیگر شکل نگیرد.

> 💡 **راهکار تکمیل ارسال اشتراکی سراسری:**
> برای اینکه پیام‌های کاربران مختلف به صورت اشتراکی در سطح وب ذخیره و خوانده شود، در همان دامنه `tk-server.ir` کافی است یک اسکریپت ساده (مانند PHP API یا Node.js) قرار گیرد که با دریافت رمز `MAXO`، فایل `CHAT-MAXO.json` را به صورت امن بنویسد و بخواند.

## 👑 حساب اولیه مالک سیستم (Initial Owner)

حساب کاربری مالک ارشد اولیه در اولین اجرای برنامه به صورت پایدار و خودکار پیکربندی می‌شود:
- **نام کاربری:** `MAXO`
- **رمز عبور اولیه:** `MAXO1212`
- **سطح دسترسی:** مالک کل (`owner`)

### ویژگی‌های امنیتی احراز هویت:
- **جلوگیری از تصاحب حساب مالک:** ثبت‌نام عمومی نام کاربری `MAXO` را به عنوان شناسه رزرو شده رد می‌کند.
- **هشینگ رمز عبور:** کلیه رمزهای عبور با الگوریتم SHA-256 همراه با نمک امنیتی (Salt) ذخیره می‌شوند؛ هیچ رمزی به صورت متن خام نگهداری نمی‌شود.
- **یکتایی نام کاربری:** تکرار نام‌های کاربری بدون حساسیت به حروف کوچک و بزرگ (Case-Insensitive) مسدود است.
- **تغییر رمز عبور:** مالک و کاربران می‌توانند رمز خود را با ارائه رمز قبلی از بخش پروفایل تغییر دهند.

## 🎨 طراحی بومی و تایپوگرافی فارسی (Vazirmatn)

- **ساختار ۱۰۰٪ بومی:** بدون استفاده از WebView، HTML یا فریم‌ورک‌های وب.
- **پالت رنگی لوکس:** پس‌زمینه مشکی عمیق (`#060709`)، کارت‌های خاکستری تیره (`#11141A`) و حباب‌های پیام سفید و شفاف.
- **فونت فارسی وزیرمتن:** فایل فونت رسمی `vazirmatn.ttf` در پوشه `res/font/` باندل شده و در تمام عناصر XML فعال است.
- **پشتیبانی کامل RTL:** چیدمان راست به چپ برای متن‌ها و کنترل‌های فارسی.
- **حباب‌های گفتگوی پیام:** پیاده‌سازی شده در `RecyclerView` همراه با نشانگر نقش فرستنده (مالک، مدیر، کاربر)، اموجی‌های واکنش (Reactions)، و نقل‌قول پاسخ (Replies).


1. صحت نام منبع برنامه (`MAXO CHAT`).
2. راه‌اندازی موفقیت‌آمیز حساب مالک اولیه `MAXO` و بررسی صحت رمز `MAXO1212`.
3. رد نام کاربری تکراری و مسدودسازی ثبت‌نام با نام کاربری اختصاصی `MAXO`.
